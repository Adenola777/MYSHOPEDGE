# The source documents

The ten documents the project was specified from, dated 20 and 21 September 2026. They are
committed here on 24 September so that the repository stops depending on a chat attachment
and one desktop folder.

**These are the source, not the current ruling.** Where a document here disagrees with an
`A` document at the repository root, the `A` document wins. The rulings were written after
these and several of them exist precisely to correct something in here. `A13` rule 1 puts
the same thing another way: the contract is the source of truth for the API, not the TRD.

They are kept because a summary is not a substitute for the thing summarised. When a ruling
says "A11 amends the ingestion scope", the only way to see what it amended is to read what
was there before.
